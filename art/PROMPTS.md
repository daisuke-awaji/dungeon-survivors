# ダンジョンサバイバーズ キャラクター・てきの画像生成プロンプト

ChatGPT の画像生成にそのまま貼って使うプロンプトです。5枚のシートで、主人公3人とてき15体をそろえます。
`art/source/` の5枚は、このプロンプトで生成したものです（背景は透明にならず、マゼンタ単色で出ました。切り抜きは `scripts/art/cut.py` で行います）。

## 進め方

1. **プロンプト1（主人公3人）を生成する。** これが絵柄の基準になります。気に入るまでここで直します。
2. **プロンプト2〜5は、1 の画像を添付して生成する。** 同じ会話の中で続けるか、新しい会話なら 1 の画像を添付してください。絵柄がそろいやすくなります。
3. **できた画像を保存する。** ファイル名は `heroes.png` / `stage1-enemies.png` / `stage1-bosses.png` / `stage2-enemies.png` / `stage2-bosses.png` にしてください。

## ゲーム側の条件（プロンプトに入れてある理由）

| 条件 | 理由 |
|---|---|
| 太い輪郭、単純な形、大きな頭 | ふつうのてきは、スマホの画面で数十ピクセルの大きさにしかならない |
| 丸くまとまった形 | 当たり判定が円なので、長い武器やしっぽが飛び出すと、見た目と当たりがずれる |
| 主人公は少し右向き、てきは真正面 | 主人公だけ、進む向きに合わせて左右反転している |
| 透明な背景、影なし | 床の上に重ねて表示する。絵に影や地面がついていると、床から浮いて見える |
| 明るい色 | 床が暗い（面1は暗い紫、面2は暗い青） |
| 1体につき絵は1枚 | いまは絵を1枚だけ使い、のびちぢみで動きをつけている |

## プロンプト1: 主人公3人（絵柄の基準）

```
ゲーム用のキャラクター素材を1枚の画像にまとめて描いてください。主人公3人を、横一列に等間隔で並べます。画像サイズは横長（3:2、1536×1024）。

【用途】スマホ向けの見下ろし型アクションゲーム（小学校高学年向け）のキャラクター素材。ゲームの中ではとても小さく（数十ピクセル）表示され、暗い色の床の上に置かれる。
【絵柄】2〜2.5頭身のちびキャラ。カジュアルなスマホゲーム風のデジタルイラスト。太くて均一な濃い紺色（#1b1530）の輪郭線、はっきりしたセル塗り（影は1〜2段階）、左上からの光でつやのあるハイライト。明るく彩度の高い色。
【形】頭と目を大きく、シルエットは丸くまとまった単純な形にする。細かい模様や細い線は入れない。武器・しっぽ・翼が体から大きく飛び出さないようにする。
【背景】完全に透明（アルファ付きPNG）。地面、足元の影、光のエフェクト、枠、文字、名前のラベル、番号は一切描かない。半透明の部分も作らない。
【配置】キャラクターどうしは重ねず、間に広い余白をあける。どのキャラクターも画像の端で切れないようにする。大きさの差はあとで調整するので、それぞれ自分のマスいっぱいの大きさで描く。全員の絵柄・線の太さ・塗り方をそろえる。
【雰囲気】かわいくて、少し手ごわそう。こわすぎる表現、血、きずの表現はなし。
【向きとポーズ】全身を足元まで描く。少し上から見下ろした正面向きで、体をほんの少しだけ右へ向ける（ゲームの中で左右反転して使う）。武器をかまえた立ちポーズを1つずつ。

【描くキャラクター（左から順に）】
1. けんし: 元気な男の子の剣士。赤い羽かざりのついた銀色のかぶと、青いよろい。右手に銀色の剣、左手に金色の丸い盾（中心に赤い宝石）。茶色のブーツ。
2. まほう使い: かしこそうな女の子のまほう使い。黄色い星のかざりがついた紫のとんがりぼうし、紫のローブ。先に水色に光る宝玉がついた木のつえを持つ。
3. とうぞく: すばしっこそうな男の子。深い緑のフードと緑の服、首に赤いスカーフ。片手に銀色の短剣。黒っぽいくつ。
```

## 絵柄を変えたいとき

各プロンプトの【絵柄】の行を、次のどちらかに入れかえます。5枚とも同じ行にしてください。

- **ドット絵**
  `【絵柄】2頭身のちびキャラ。レトロゲーム風のピクセルアート（ドット絵）。1体を 48×48 ドットくらいの粗さで描く。濃い紺色（#1b1530）の輪郭線、1体あたり12色以内、ぼかしやグラデーションなし。`
  注意: 生成されたドット絵はドットの大きさがそろわないことが多く、縮小するとにじみます。
- **厚塗りのファンタジー風**
  `【絵柄】2.5頭身のちびキャラ。厚塗りのファンタジーイラスト風。やわらかい陰影と質感（金属のつや、毛なみ）。濃い紺色（#1b1530）の輪郭線、ふちに明るいリムライト。明るく彩度の高い色。`
  注意: 描きこみが細かくなるので、小さく表示すると、つぶれて見えにくくなることがあります。

## うまくいかないとき

| 起きたこと | 追加で頼む文 |
|---|---|
| 背景が透明にならない | `背景を、単色のマゼンタ（#FF00FF）でぬりつぶしてください。グラデーションや影はなし。` |
| キャラクターどうしがくっつく、重なる | `キャラクターの間の余白を、いまの2倍に広げてください。` |
| 名前や番号の文字が入る | `文字、ラベル、番号をすべて消してください。` |
| 1体だけ絵柄がちがう | `左から2番目だけ、ほかと同じ線の太さと塗り方で描き直してください。ほかは変えないでください。` |
| 足元に影や地面がつく | `足元の影と地面を消してください。` |

## 生成したあとに見るところ

- 背景が透明になっている（または単色でぬられている）
- キャラクターどうしが重なっていない。端で切れていない
- 5枚で、線の太さと塗り方がそろっている
- 画面を小さくして見ても、何のキャラクターかわかる
- 面2のてき（白・水色）が、暗い青の上で見分けられる
