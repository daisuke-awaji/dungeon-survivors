# ダンジョンサバイバーズ 計画書

## 1. ねらい

小学校高学年（10〜12歳）の男の子が、スマホで「もう1回」と遊びたくなるローグライク・サバイバーゲームを作る。

- 縦持ち・指1本で遊べる
- 1プレイ約5分
- ブラウザだけで動き、GitHub Pages で公開する
- 通信・広告・課金・個人情報の入力は一切なし

## 2. ゲーム仕様

### 2.1 基本ルール

| 項目 | 内容 |
|---|---|
| 操作 | 画面のどこでもドラッグで移動（仮想スティック）。こうげきは自動 |
| 目的 | 5分間生き残る（クリア）。5:00 に出るドラゴンをたおすと完全クリア |
| 成長 | 経験値ジェムを集めてレベルアップ → スキルを3つから1つ選ぶ |
| 所持数 | 武器4つ・パッシブ4つまで。それぞれ最大 Lv5 |
| 進化 | 武器が Lv5 で、対応するパッシブを持っていると、レベルアップ時に進化を選べる |
| 敗北 | HP が 0 になるとゲームオーバー（「ふっかつ」を買っていれば1回だけ復活） |

### 2.2 武器（6種）と進化

| 武器 | 動き | 進化に必要なパッシブ | 進化後 |
|---|---|---|---|
| ソード | 向いている方向をなぎはらう | パワーリング | エクスカリバー（全方向） |
| マジックショット | 近くのてきにたまを飛ばす | まほうの本 | スターバースト（連射・つらぬく） |
| ファイアボール | 当たるとばくはつする | ビッグキノコ | メテオ（空からふってくる） |
| サンダー | 画面内のてきにかみなりを落とす | スピードブーツ | サンダーストーム |
| まわるシールド | 自分のまわりを回ってぶつける | ハートのうつわ | ホーリーシールド |
| アイスウェーブ | 氷の輪を広げ、てきをおそくする | マグネット | ブリザード（こおらせる） |

### 2.3 パッシブ（6種）

| パッシブ | 効果（1レベルごと） |
|---|---|
| パワーリング | ダメージ +10% |
| まほうの本 | こうげき間かく -8% |
| ビッグキノコ | はんい +10% |
| スピードブーツ | 移動速度 +8% |
| ハートのうつわ | 最大HP +20%（取ったときに回復） |
| マグネット | アイテムを拾えるきょり +30% |

### 2.4 てき（面1「ダンジョン」）

| 時間 | 出てくるてき |
|---|---|
| 0:00〜 | スライム |
| 0:30〜 | コウモリ（速い・群れ） |
| 1:00〜 | ゴブリン |
| 2:00〜 | ガイコツ |
| 2:30 | 中ボス「オークキング」 |
| 3:00〜 | ゴースト |
| 3:30〜 | オーク |
| 5:00 | ボス「ドラゴン」（火の玉をはく） |

- 時間とともに出現数と HP が上がる。
- 同時に出る数には上限を設け、処理落ちを防ぐ。
- 血などの表現はなし。てきはポンと消える。

### 2.5 アイテム

経験値ジェム（小・中・大）、コイン、ハート（回復）、じしゃく（画面内のジェムを全部引きよせる）。

### 2.6 やり込み要素（端末に保存）

- コインで買える永続強化: こうげき力 / 最大HP / 移動速度 / 経験値 / コイン / ふっかつ
- キャラクター3人: けんし（最初から使える）、まほう使い、とうぞく（コインで解放）
- 最高記録（生き残った時間・たおした数・レベル・クリア）。面ごとに別々に残す
- 面2「氷のどうくつ」: 面1のドラゴンをたおすと遊べるようになる（2.9）

### 2.7 画面

タイトル → （キャラクター選択 / 強化ショップ） → ゲーム（HUD・レベルアップ・ポーズ） → 結果

### 2.8 文言

日本語。漢字は小学校で習うものだけを使い、迷うものはひらがな・カタカナにする。

### 2.9 面2「氷のどうくつ」

面1のドラゴンをたおすと、タイトル画面の面えらびで選べるようになる。長さ（5分＋最後のボス）、武器、コインの計算は面1と同じ。てきは全部べつの種類で、面1より強い。

| 時間 | 出てくるてき |
|---|---|
| 0:00〜 | アイススライム |
| 0:20〜 | ゆきコウモリ（速い・群れ） |
| 0:50〜 | こおりオオカミ（赤く光ってかまえたあと、まっすぐ走ってくる） |
| 1:40〜 | ゆきだるま（はなれた所から雪玉を投げる） |
| 2:30 | 中ボス「イエティ」（とっしんのあと、雪玉を3方向に投げる） |
| 3:10〜 | アイスゴーレム（おそいが、かたくて痛い） |
| 5:00 | ボス「氷のドラゴン」（ねらって3れん発、または全方向に2れん発の氷の玉。当たると 1.5 秒、移動速度が 0.6 倍になる） |

- てきの玉（ボスの玉もふくむ）が 10 個あるあいだは、ふつうのてきは雪玉を投げない。画面の外からは投げてこない。
- てきの玉は、ジェムとまちがえないよう赤くふちどる。
- 難易度のねらい: 永続強化なしではほぼクリアできず、全強化レベル2＋ふっかつ（合計 800 コイン）で半分くらいクリアできる。自動プレイ（うまさ 0.5）で目安を確認する。
- 面のデータ（出現表・ボス・床・強さ）は `src/data/stages.ts` にまとめる。面を足すときは、ここと `src/data/enemies.ts`、絵（`src/gfx/sprites.ts`）を足す。

## 3. 技術構成

| 項目 | 採用 |
|---|---|
| ゲームエンジン | Phaser 3（3.90 系） |
| 言語・ビルド | TypeScript + Vite |
| 画像 | なし。Canvas 2D で1枚のテクスチャアトラスを起動時に生成 |
| 音 | なし。Web Audio API で効果音を合成（ミュート可） |
| 保存 | localStorage（キー: `dungeon-survivors:save:v2`）。読み込み時に検証し、こわれていたら初期値にもどす。面が1つだけだったころのセーブ（`...:save:v1`）は、新しいセーブがないときだけ読んで引きつぎ、書きかえない |
| テスト | Vitest（純粋ロジック） |
| 静的解析 | ESLint（typescript-eslint）、`tsc --noEmit` |
| デプロイ | GitHub Actions → GitHub Pages |

### 3.1 ディレクトリ

```
src/
  main.ts            Phaser の起動
  config.ts          画面サイズなどの定数
  data/              武器・パッシブ・てき・面（出現表・ボス）・キャラクター・永続強化
  logic/             Phaser に依存しない純粋ロジック（テスト対象）
  gfx/               テクスチャ生成
  audio/             効果音
  game/              プレイ中のシステム（てき・武器・アイテム・演出）
  scenes/            Boot / Title / Shop / Game / Hud
tests/               Vitest
```

### 3.2 設計方針

- **ロジックと描画の分離**: レベル曲線、スキル抽選、ステータス計算、出現表、報酬計算、セーブ検証、空間グリッドは Phaser に依存させず、単体テストする。
- **性能**: てき・たま・アイテム・ダメージ数字はオブジェクトプールで再利用。当たり判定は自前の空間グリッド。スプライトは1枚のアトラスにまとめて描画バッチを切らない。
- **画面サイズ**: 横 720 の論理解像度、高さは端末の縦横比から決める。`Scale.FIT` で拡大縮小。
- **安全性**: 外部通信なし。セーブデータは型と範囲を検証してから使う。

## 4. 実装ステップ

1. 土台: Vite + TypeScript + Phaser 3、ESLint、Vitest、npm scripts
2. 純粋ロジックとデータ定義、単体テスト
3. テクスチャ生成、効果音
4. ゲーム本体: 移動、てきの出現と追跡、当たり判定、ジェム、レベルアップ
5. 武器6種と進化、ボス2体
6. タイトル、キャラクター選択、強化ショップ、結果画面、セーブ
7. 演出: ダメージ数字、画面のゆれ、パーティクル
8. GitHub Actions（lint・typecheck・test・build・Pages デプロイ）
9. ヘッドレス Chromium（スマホ画面サイズ）で動作確認、自動プレイで難易度を確認

## 5. 受け入れ条件

- [ ] スマホ縦画面で、ドラッグだけで移動できる
- [ ] てきが時間とともに増え、2:30 と 5:00 にボスが出る
- [ ] レベルアップで3択が出て、選んだスキルが反映される
- [ ] 武器6種・パッシブ6種・進化6種が動く
- [ ] コイン、永続強化、キャラクター解放、最高記録がリロード後も残る
- [ ] 効果音が鳴り、ミュートできる
- [ ] `npm run lint` / `npm run typecheck` / `npm test` / `npm run build` が通る
- [ ] GitHub Pages の公開URLで遊べる

## 6. リスク

| リスク | 対処 |
|---|---|
| てきが多いときのスマホでの処理落ち | プール、空間グリッド、同時出現数の上限、1アトラス |
| 難易度バランス | 自動プレイで目安を確認。実機で遊んだ感想をもとに公開後も調整 |
| iOS Safari で音が出ない | 最初のタップで AudioContext を開始 |
| 画面の向き・サイズの違い | 縦横比から論理高さを決め、横画面では中央に縦長で表示 |
